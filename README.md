# Curitiba-a-Recife-Planeamento-Financeiro-em-C-digo
A transformar tabelas em gráficos interativos. Criei um dashboard para organizar as despesas da viagem de Curitiba a Recife. Com recurso a Chart.js, HTML5 e CSS3, é possível acompanhar os custos finais por categoria, identificar o maior gasto e manter o orçamento sob controle
